# Key insights (all from real DGHS + NASA data)
- 2023 was the record outbreak: 321,179 cases; peak month Sep 2023 (79,598).
- Cases peak Aug-Oct, ~2 months after peak rainfall - a usable early-warning window.
- Random Forest regression: R2 (log) = 0.6822, MAE = 6886.1 cases on 2020-2024.
- Outbreak detection ROC-AUC = 0.9101 (Random Forest), vs 0.89 in Rahman & Shiddik (2025).
- Top SHAP feature: cases_lag1 - outbreaks build on the previous month.
